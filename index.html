방문 체크

건물 사진을 찍으면, 찍은 위치로 어느 건물을 방문했는지 자동으로 체크해요.

실제 GPS로 찍어요. 덕수궁이 아니어도 돼요 — 동네 공원에 건물 배치를 옮겨 테스트할 수 있어요. 위치·방향 권한은 지금, 카메라는 첫 촬영 때 물어봐요.

지도를 탭한 곳을 내 위치로 써요. 집이나 PC에서 판정을 미리 보기 좋아요.

방문 기록

    촬영 로그 — 탭해서 실제 건물 기록

      사진은 이 기기에만 남아요. Safari는 오래 안 쓰면 사이트 데이터를 지울 수 있으니 테스트 후 내보내 두세요.

      실제로 찍은 건물은?

      사용법

      사진을 찍는 순간의 위치(+방향)로 어느 건물 앞에서 찍었는지 판정해 자동으로 체크해요. 사진 내용은 보지 않아요.

      어떻게 쓸까요?

      집에서 둘러보기 — 시뮬레이션
      1. 시작 화면에서 "시뮬레이션으로 둘러보기"
      2. 지도를 탭하면 그곳이 내 위치예요. 아래에 "지금 찍으면 → 건물 (확률)"이 떠요.
      3. 📷 촬영 → 그 건물이 초록색으로 체크되고 위의 진행률(n / 전체)이 늘어요.

      ⚙︎ 설정에서 GPS 오차·방향을 바꾸면 판정이 어떻게 달라지는지 볼 수 있어요.

      동네 공원에서 현장 테스트 — 정확도 측정

      덕수궁 건물 배치(약 310 × 290 m)를 내 주변으로 옮겨, 가상 건물을 실제 GPS로 찍어 봐요.

      1. 넓은 공원에서 "현장에서 시작" → 위치·방향 권한 허용
      2. 배치에서 멀리 있으면 아래에 "내 주변으로 건물 배치 옮기기" 버튼이 떠요. 누른 뒤 회전으로 공원 모양에 맞추고 "완료". (⚙︎ 설정 → 배치 옮기기·회전으로도 할 수 있어요)
      3. ⚙︎ 설정 → "테스트 모드" 켜기. 판정과 내 위치 점이 숨겨져요(◎는 배치 전체를 보여 줘요) — 지도 바탕(길·나무·시설)을 보고 가상 건물 앞에 서세요.
      4. 건물 쪽을 향해 📷 촬영 → "실제로 찍은 건물은?"에서 정답 선택 → 그때 판정이 맞았는지 보여요.
      5. 위의 진행률(n / 전체) → 정답률 확인 → "기록 내보내기 (JSON)"로 보관
      실제 덕수궁에서
      1. 배치를 옮겼다면 되돌려요. 덕수궁 근처에서는 아래에 "덕수궁 실제 위치로 되돌리기" 버튼이 떠요. (⚙︎ 설정에도 있어요)
      2. 나머지는 동네 테스트의 3~5번과 같아요.

      실제 덕수궁에서는 건물이 닫힌 채(회색) 시작하고 촬영 존도 숨겨져요. 찍으면 그 건물이 열려요 — 테스트 모드에서는 정답을 기록한 순간, 테스트 모드를 끄면 촬영하자마자 판정된 건물이 열려요.

      진행률은 0부터 다시 세요. 이전 기록은 지워지지 않고 내보내기에 모두 들어가요.

      지도 보는 법

      • 건물
      • 촬영 존 — 이 안에서 건물 쪽을 찍으면 그 건물로 판정
      • 체크된(열린) 건물
      • 닫힌 건물 — 실제 덕수궁 현장 모드에서 아직 안 찍은 건물
      • 지금 찍으면 체크될 건물
      • 내 위치 (옅은 원 = GPS 오차, 부채꼴 = 폰이 향한 방향)
      • 궁 경계

      테스트 모드를 켜고 끄면

      • 끔: 찍기 전에 판정이 보여요. 촬영 흐름(UX) 확인용이라 정답률에 들어가지 않아요.
      • 켬: 판정을 숨기고, 찍은 뒤 정답을 기록해요. 정답률은 이 촬영만 세요.
      • "방향 반영"은 켜든 끄든 위치만 / 위치+방향 두 판정이 모두 기록돼요. 무엇으로 체크할지만 바뀌어요.

      막힐 때

      • "…km 떨어져 있어요": 배치에서 500 m 넘게 떨어지면 촬영을 기록하지 않아요. 아래 버튼으로 배치를 옮기거나 되돌리세요.
      • "위치 신호가 끊겼어요": 잠시 기다리거나 ◎를 누르세요. 30초 넘게 새 위치가 없을 때 ◎를 누르거나 화면을 다시 켜면 위치를 다시 요청해요.
      • "위치가 부정확해요": 하늘이 트인 곳에서 잠시 기다리세요. iPhone은 "정확한 위치", Android는 "정확한 위치 사용"을 켜야 해요.
      • 권한을 거부했다면: 브라우저 설정에서 위치·카메라를 허용하고 새로고침하세요.
      • 사진과 기록은 이 폰에만 저장돼요. 테스트가 끝나면 바로 내보내세요.
